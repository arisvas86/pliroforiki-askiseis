💻 1ο Μάθημα Πληροφορικής

Τι είναι ένας ιστότοπος;

🎯 Τι θα μάθω;

  • Τι είναι ένας ιστότοπος.
  • Τι είναι μια ιστοσελίδα.
  • Τι είναι ένας σύνδεσμος.
  • Τι μπορεί να περιέχει μια ιστοσελίδα.

🧩 1. Αντιστοίχισε

Πάτησε έναν όρο και μετά τη σωστή περιγραφή.

✅ 2. Σωστό ή Λάθος

1. Ένας ιστότοπος μπορεί να έχει πολλές ιστοσελίδες.

2. Μια ιστοσελίδα δεν μπορεί να έχει εικόνες.

3. Ένας σύνδεσμος μπορεί να μας οδηγήσει σε άλλη σελίδα.

🎯 3. Πολλαπλής επιλογής

1. Τι είναι ένας ιστότοπος;

2. Τι μπορεί να έχει μια ιστοσελίδα;

3. Τι κάνει ένας σύνδεσμος;

🏫 4. Δημιουργώ τον ιστότοπο του σχολείου

Γράψε 3 σελίδες που θα ήθελες να έχει ο ιστότοπος του σχολείου.

🏆 5. Τελική επανάληψη

Ποια πρόταση είναι σωστή;
